这里只有三条，但每条都在源码里有对应的约束。

## 这些数值不是原创的

它们是**实测**来的：用真实浏览器读数（1440 视口，抓 computed style）量了一批信息密集型中文界面，
得到真实在用的 token —— 主色 `#624aff`、中性四档、12px 为主的小字、4px 起的圆角阶梯、几乎为零的阴影。

这套骨架之上，我们补了两件更关键的事：

1. **主题可切换**：4 套内置主题 × 明暗，一行属性就切，使用方还能覆盖任何一层。
2. **对比度达标**：原始读数里的三级文字 `#8284A4` 只有 3.63:1，不达 AA；我们抬到 5.00:1。
