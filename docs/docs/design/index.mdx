# 设计

一套组件库的「气质」不是靠某个组件好看，而是靠**一组不许破的规则**。
这里只有三条，但每条都在源码里有对应的约束。

## 这些数值不是原创的

它们是**实测**来的：参照 ModelScope 魔搭社区的界面，用真实浏览器读数（1440 视口，抓 computed style），
得到它真实在用的 token —— 主色 `#624aff`、中性四档、12px 为主的小字、4px 起的圆角阶梯、几乎为零的阴影。

我们抄了它的骨架，补了两件它没有的事：

1. **主题可切换**：它只有明暗两套、品牌色写死；这里 4 套 × 明暗，且使用方能覆盖任何一层。
2. **对比度达标**：它的三级文字 `#8284A4` 只有 3.63:1，不达 AA；我们抬到 5.00:1。
