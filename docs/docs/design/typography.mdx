# 字体与字号

## 字体族

| 用途 | 字体栈 |
|---|---|
| 正文 | `'PingFang SC', 'Microsoft YaHei', 'Helvetica Neue', Helvetica, Arial, sans-serif` |
| 数值 / 代码 | `'Roboto Mono', ui-monospace, Menlo, Consolas, monospace` |

中文界面不要用衬线体，也不要引入网络字体——首屏一段字体加载失败，整页排版会崩。
数值用等宽并开 `font-variant-numeric: tabular-nums`，这样列表里数字才会上下对齐。

:::note 为什么正文是 14 而不是 16
信息密集型列表页里 12px 是主体字号——密度是「小字 + 大间距」堆出来的。
但纯 12px 做正文对中文太狠，所以正文取 14，**只有元信息才下到 12**。
:::

## 3 档字重

<Demo layout="block">
  <div style={{ display: 'flex', gap: 28, alignItems: 'baseline', flexWrap: 'wrap' }}>
    <Text size="lg" weight={400}>400 Regular</Text>
    <Text size="lg" weight={500}>500 Medium</Text>
    <Text size="lg" weight={600}>600 Semibold</Text>
  </div>
</Demo>

**没有 700/800。** 中文在 700 以上字重会开始糊，且大多数系统字体没有对应的真字重，
浏览器只能做合成加粗——那看起来比不加粗更廉价。
