## 一句话定位

orange-ui 面向**信息密集但仍要有温度**的界面：模型社区、内容平台、AI 工作台。
它的视觉基线是「高密度小字 + 低阴影 + 细边框」，活泼只允许出现在 16px 彩色图标和品牌渐变里。
所以它不像后台管理系统，也不该被用成后台管理系统。
