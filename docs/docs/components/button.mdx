# Button 按钮

页面上唯一确定性的动作。**一屏只留一个实心主按钮**，其余降级为描边、浅底或纯文字——
强调色出现的次数，就是这页信息的层级。

按钮的高度由 `size` 决定（24 / 28 / 32 / 40），默认 32；圆角固定 4px，
因为它是「工具」不是「气泡」。加载时**锁定原宽度**：文字位置不动，只把左边图标换成转圈。

```tsx
import { Button } from '@arvinzxy/orange-ui';
```

## 形态 variant

五种形态按「视觉重量」从重到轻排列。同一区域里越靠后的动作，用越轻的形态。

<Demo layout="block">
  <div style={{ display: 'flex', gap: 12, flexWrap: 'wrap' }}>
    <Button variant="solid">solid 实心</Button>
    <Button variant="outlined">outlined 描边</Button>
    <Button variant="soft">soft 浅底</Button>
    <Button variant="ghost">ghost 幽灵</Button>
    <Button variant="text">text 文字</Button>
  </div>
</Demo>

## 角色色 color

`color` 声明这个按钮代表哪种语义，不代表「我想让它变彩色」。
一个页面里 `danger` 只该出现在真正不可逆的操作上。

## 尺寸 size

四档高度对应四种信息密度：`xs` 给表格行内，`lg` 给落地页主 CTA。
**同一行里的按钮必须同尺寸**，混排会让整行基线错位。

<Demo>
  <Button size="xs">xs · 24</Button>
  <Button size="sm">sm · 28</Button>
  <Button size="md">md · 32</Button>
  <Button size="lg">lg · 40</Button>
</Demo>

## 加载中

`loading` 会做三件事：左侧图标换成转圈、**锁定当前宽度**、`aria-busy="true"` 并阻断点击。
需要换文案时传 `loadingText` —— 注意它会改变按钮宽度，只有在容器本来就能容纳时才用。

<Demo>
  <Button loading>保存中</Button>
  <Button loading loadingText="正在发布…">发布</Button>
  <Button variant="outlined" loading>同步</Button>
  <Button loading disabled>禁用的加载态</Button>
</Demo>

```tsx
{/* 只转圈，原文字隐形以锁住宽度 —— 列表里批量提交时不会让整行抖动 */}
<Button loading>保存中</Button>

{/* 需要换文案时用 loadingText，接受宽度变化 */}
<Button loading loadingText="正在发布…">发布</Button>
```

## 渲染成链接

给了 `href` 就渲染成 `<a role="button">`。用于**跳转**——真正的导航请用 [Link](/components/link) 组件，
语义更正确，也能被浏览器和读屏当作链接处理。

<Demo>
  <Button href="#button-按钮" variant="outlined">跳到本页顶部</Button>
</Demo>

## 无障碍

- 加载态自动带 `aria-busy="true"`，并阻断点击
- 纯图标按钮必须传 `aria-label`
- 焦点环只在键盘操作时出现（`:focus-visible`），鼠标点击不出现
- 实心按钮上的文字按主题色**自动取深墨或白色**，保证 ≥ 4.5:1
